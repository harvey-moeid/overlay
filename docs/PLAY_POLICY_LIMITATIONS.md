# Distribusi dan batasan

Experimental Agent ditujukan untuk APK pribadi/sideload. Itu bukan pengecualian kebijakan Google Play. Jangan mengklaim aplikasi ini accessibility tool untuk disabilitas; service tetap isAccessibilityTool=false. Kebijakan Google Play melarang agent aplikasi biasa menggunakan Accessibility untuk secara otonom memulai/merencanakan/mengeksekusi aksi; audit terpisah diperlukan sebelum rencana distribusi Play.

Tidak ada bypass FLAG_SECURE, authentication/OTP/2FA, lockscreen, DRM, privacy prompt atau pembatasan platform. Tidak ada root/ADB/Shizuku/backend. Vision, bank, pembayaran dan operasi publikasi agent tidak diimplementasikan. Aplikasi target lain belum terbukti kompatibel dan adapter agent tetap dibatasi ke harness BYGA. User tetap melakukan login/pindah akun/posting melalui fitur resmi aplikasi.

Referensi: https://support.google.com/googleplay/android-developer/answer/10964491
